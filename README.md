# مسودة إضافة إعلان — طلبك تم

تطبيق **منفصل تماماً** عن مشروع «طلبك تم» الفعلي — لا يلمس Supabase ولا الموقع ولا الأدمن.
الهدف: الموظف الميداني يسجّل تفاصيل الإعلان (شقة/سيارة/معدة...) فور المعاينة بدل ما يكتبها على واتساب،
وموظف الأدمن يتصفح "المعلقات" لاحقاً وينقلها يدوياً للأدمن الحقيقي، وبعدين يعلّمها كمُنجزة فتُحذف.

## الفكرة

```
موظف ميداني                     Firestore (سحابة منفصلة)                 موظف الأدمن
  يفتح التطبيق                                                          يفتح نفس التطبيق
  يضغط + (إضافة)      ──save──▶      قائمة "المعلقات"      ◀──يقرأ──      يتصفح المعلقات
  يملأ نفس حقول الأدمن                                                    ينسخ البيانات لأدمن طلبك تم
  حسب فئة الإعلان                                                         يضغط ✓ فتُحذف المسودة
```

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الهيكل: شاشة المعلقات + شاشة النموذج + شاشة التفاصيل |
| `styles.css` | التصميم — نفس ألوان لوحة تحكم طلبك تم (برتقالي `#F6921E`) |
| `app.js` | كل المنطق: الفئات، الحقول الديناميكية، الحفظ، القراءة، الحذف |
| `firebase-config.js` | إعدادات مشروع Firebase (فارغة افتراضياً — املأها حسب الخطوات تحت) |
| `manifest.json` + `sw.js` | تثبيت التطبيق كـ PWA + عمل أوفلاين |

## خطوة 1: إنشاء مشروع Firebase منفصل (5 دقائق)

1. افتح **https://console.firebase.google.com**
2. **Add project** → اسم مثل `talabaktam-drafts` (مشروع جديد كلياً، لا علاقة له بأي شيء آخر)
3. من القائمة الجانبية: **Build → Firestore Database → Create database**
   - اختر **Start in production mode**
   - اختر أقرب منطقة (مثلاً `eur3` أو `europe-west1`)
4. **⚙ Project settings → General → Your apps** → اضغط أيقونة الويب `</>`
   - سجّل اسم تطبيق (أي اسم) → **Register app**
   - سينسخ لك كائن يشبه هذا:
     ```js
     const firebaseConfig = {
       apiKey: "AIzaSy...",
       authDomain: "talabaktam-drafts.firebaseapp.com",
       projectId: "talabaktam-drafts",
       storageBucket: "talabaktam-drafts.appspot.com",
       messagingSenderId: "...",
       appId: "..."
     };
     ```
5. افتح ملف `firebase-config.js` هنا والصق القيم مكان الفراغات.

## خطوة 2: تفعيل تسجيل الدخول (Authentication)

التطبيق محمي بتسجيل دخول بالبريد وكلمة السر — لا أحد يشوف المسودات إلا موظفوك.

1. من قائمة Firebase: **Build → Authentication → Get started**
2. تبويب **Sign-in method** → فعّل **Email/Password** → Save
3. تبويب **Users** → **Add user** → أدخل بريد وكلمة سر لكل موظف
   (مثلاً `field1@talabaktam.com` للموظف الميداني، `office@talabaktam.com` لموظف الأدمن)
4. ⚠️ **لا تفعّل التسجيل الذاتي** — أنت من ينشئ الحسابات يدوياً من هذه الصفحة فقط

> لإضافة موظف جديد لاحقاً: نفس الخطوة 3. لإيقاف موظف: من نفس الصفحة اضغط **Disable**.

## خطوة 3: قواعد الحماية (Firestore Rules)

الصق هذا في **Firestore Database → Rules → Publish**:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /drafts/{draftId} {
      allow read, write: if request.auth != null;
    }
  }
}
```

هذا يعني: **فقط من سجّل دخوله بحساب موظف** يقدر يقرأ أو يكتب أو يحذف المسودات.

> 🔴 **مهم:** لا تستخدم `if true` بدل `if request.auth != null`. المستودع عام على GitHub،
> يعني إعدادات Firebase مكشوفة للجميع — ومع `if true` أي شخص بالعالم يقدر يقرأ مسودات
> موظفيك (أرقام العملاء وصورهم) ويحذفها. مفاتيح Firebase ليست سرّاً بطبيعتها؛
> الحماية الحقيقية تأتي من هذه القواعد.

## خطوة 4: النشر كـ PWA

نفس أسلوب مشروع الأدمن — إما:
- **Cloudflare Pages**: مجلد مستقل، اربطه بنطاق فرعي مثل `draft.talabaktam.com`
- أو حتى تشغيل محلي/شبكة داخلية إذا الفريق صغير

بعد النشر، كل موظف يفتح الرابط على موبايله ويضغط **"إضافة إلى الشاشة الرئيسية"** ليصير تطبيق مثبّت.

## بدون Firebase؟

إذا تركت `firebase-config.js` فارغاً، التطبيق يشتغل بوضع **"محلي فقط"** (يظهر شارة حمراء بالأعلى) —
المسودات تنحفظ على متصفح ذاك الجهاز فقط ولا تتشارك بين الموظفين. مفيد للتجربة السريعة فقط.

## الفئات المدعومة

مطابقة تماماً لفئات أدمن طلبك تم: شقق (إيجار/بيع)، سيارات، معدات، محلات تجارية، أراضي، مهن وخدمات —
مع نفس الحقول التفصيلية لكل فئة (غرف/حمامات للشقق، ماركة/موديل للسيارات... إلخ).

## سير العمل اليومي

1. **الموظف الميداني**: يعاين عقار/سيارة → يفتح التطبيق → **+** → يختار الفئة ← الحقول تتغيّر تلقائياً → يملأ ويصوّر → **حفظ بالمعلقات**
2. **موظف الأدمن**: يفتح تبويب **المعلقات** → يضغط على أي مسودة ليشوف كل التفاصيل → ينسخها يدوياً لنموذج إضافة الإعلان بالأدمن الحقيقي (Supabase) → بعد الحفظ هناك، يرجع هنا ويضغط **✓ تمّت إضافته** فتُحذف المسودة نهائياً
